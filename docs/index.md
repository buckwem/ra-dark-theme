# RA Dark Theme

RA Dark Theme is a complete Joomla/Gantry template with a light/dark switch.
It retains the supplied Ramblers layouts, Assistant font settings and module
positions, with compact sun/moon icons and optional weather colour matching.

Start with [installation](installation.md), then choose your
[default appearance](configuration.md). The complete source is in `template/`
and `make package` builds the installable ZIP.

Version **0.2.0-beta5** is a beta. The template was installed and previewed on
Alton Ramblers; wider update, removal and compatibility checks remain necessary.
See [testing](testing.md) for evidence and limitations.
