# RA Dark Theme

RA Dark Theme adds a light/dark switch to Ramblers websites using Gantry 5
Hydrogen. It is a Joomla system plugin with its own assets and visitor settings.
It is independent of Festive Overlay.

The starting palette was reviewed on 162 local Alton Ramblers pages. It covers
articles, contacts, walks, calendars, menus, gallery frames and map controls.
It preserves the website's original font families and does not invert images.

The title-bar switch uses Prodockit's Lucide sun/moon icons at 18 pixels.
The visible button is 32 pixels; its pointer target is 44 pixels. Labels explain
the action, and the control supports normal keyboard operation and focus.

**0.1.0-beta2** targets Joomla 5.4 and 6.x with PHP 8.3+. Real Joomla installation,
update and removal checks remain outstanding. See [testing](testing.md) for the
scope of the completed checks and what remains before a production release.

Start with [installation](installation.md), then review the
[configuration settings](configuration.md).
