# Contributing

Report problems and suggest improvements through this repository's public
GitHub Issues. Include your Joomla version, the package version, steps to
reproduce the problem and the expected behaviour. Remove passwords, access
tokens and other private information from screenshots and logs.

To propose a change, fork the repository, create a branch and open a pull
request against `main`. Describe the change and how you tested it. Follow
`AGENTS.md` for the repository's source and documentation conventions.

Pull requests into `main` require review by @buckwem. New changes dismiss
previous approvals. Workflows on pull requests from outside contributors
require maintainer approval before running. Workflow approval permits checks
to run; it does not approve merging the change.
