# Changelog

## 0.2.0-beta2 template (21 November 2026)

- Use absolute asset URLs to avoid Joomla prefixing root-relative template asset paths with a second slash.


## 0.2.0-beta1 template (21 November 2026)

- Added a standalone Gantry template builder using the administrator-supplied Hydrogen template.
- Added built-in light/dark controls and Joomla template-style parameters.
- Preserved the Ramblers layout and styles through a portable base outline.
- Kept site-specific packages local and documented staging installation and rollback.


## 0.1.0-beta2 (21 November 2026)

- Fixed asset URLs for Joomla installations whose root path ends in a slash.
- Added regression checks for root and subdirectory installations.

## 0.1.0-beta1 (21 November 2026)

- Packaged the reviewed Ramblers dark theme as an independent Joomla system plugin.
- Added device/light/dark defaults, saved preferences and compact sun/moon controls.
- Added template scoping, Joomla asset registration and weather colour matching.
- Added reproducible packaging, behaviour checks, CI and Zensical/Prodockit documentation.
- Retained beta status pending installation, update and uninstall checks on Joomla.
